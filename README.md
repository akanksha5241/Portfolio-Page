# Portfolio-Page

A clean, responsive personal portfolio website built using HTML and CSS. This project showcases professional details and visuals in a modern and minimalistic design.

---

##  Technologies Used
- **HTML** – for the structure of the content.
- **CSS** – for styling and layout (`main.css`).
- **Images** – visual assets stored in the `images/` folder.

---

##  How To Run
- simply click on index.html file and show the page
